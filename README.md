### Home Credit Default Risk Prediction

Developed a credit-risk prediction pipeline using Python, pandas, NumPy, scikit-learn, and LightGBM. The project integrates application, previous-loan, credit-bureau, installment-payment, and credit-card data, then applies feature engineering and aggregation to create customer-level financial indicators.

Implemented memory-efficient data processing, missing-value analysis, categorical encoding, credit and debt ratios, repayment-delay indicators, and historical application statistics. Trained a LightGBM classifier with validation-based early stopping and AUC evaluation, generated default-risk probabilities, and exported predictions for submission. The project demonstrates experience in data integration, feature engineering, financial risk modelling, gradient-boosting algorithms, model evaluation, and large-scale tabular data analysis.
